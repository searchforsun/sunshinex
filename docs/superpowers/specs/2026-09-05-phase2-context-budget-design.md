## 交付结论

- 压缩预算闭环达成：压缩后重装配重估、收敛环至多 2 轮有界收敛，多文件全文汇总场景 prompt 估算全程不超总预算——旧实测 20K 级失控曲线消除，且压缩当轮即以收敛后条目生效（验收 C1）。
- 估算口径解耦：token 估算改为 CJK 计一、其余除四的真实近似，触发滞后根治；原 kind 权重自估算退役、转作压缩丢弃优先级，语义各归其位。
- 记忆水位治理：记忆记录入口限长、注入改分层配额（skill 优先保全、层间按价值梯度取尾），旧记忆由压缩摘要代表、叠加通道关闭（验收 C3）。
- 注入块预算化：压缩摘要按确定性丢弃序裁剪（system/instruction 白名单不可丢、截断确定性保 checksum 幂等），重读按最旧整文件先丢且只做预算裁剪不摘要化（验收 C2）。
- 滞回约束压缩频次：距上次压缩至少 2 个新步方可再压，est 硬越限应急旁路不受滞回限制——频次受控与收敛保证互补（验收 C4）。
- 语义保持与边界：真实模型冒烟自主收敛、任务结论正确；既有用例仅数字行白名单重校、断言语义零改动（验收 C5，113/113/0）；不做真实 tokenizer（零依赖约束、近似误差文档化）、观测 2000 字符分页读另立 spec、预算参数不新加配置面。
