## 交付结论

- 一切进入模型上下文的文案恒为英文单语：工具描述/观察/错误/链行/摘要与记忆提示词/角色框定等全量英文化，同一意图不再维护双语两套语料（98 处 pick() 双语调用删除，i18n 收窄为纯外观显示）。
- 真泄漏修复：143 处未经包装直入模型上下文的中文串清零；归属唯一判据=「能否被模型读到」，而非「是否上屏」。
- 关键裁决 B-1：执行面按「是否写链」二分——写链行英文，纯上屏回执字面量保留双语（初版把 graph/loop 全层判英文的误判在此更正）。
- 零泄漏审计用例钉死回归（按「是否被 t() 包裹」扫描 CJK 字面量），界面双语用例与相邻步前缀稳定回归保持绿。
- 取舍：英文为重拟而非逐字直译，中文语料删除后代码内不可回溯（依赖 git 历史）；不做词典文件与语言配置项，产出语言规则不变。
