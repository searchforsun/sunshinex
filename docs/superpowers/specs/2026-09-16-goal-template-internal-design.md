## 交付结论

- 交付「/goal 用户面零模板暴露」：模板概念从 TUI /goal、CLI run、帮助与手册全部用户可见面整体摘除，/goal 语义对标 Claude Code——只有目标，没有装配参数。
- 关键裁决「一切即目标文本」：/goal 之后全部内容（含看似 flag 的 `--template=…` 字样）原样作为目标文本进链，不做静默剥离——静默剥离等于行为上承认该语法仍存在，与「不暴露」矛盾；以钉子用例锁定该语义。
- 关键取舍「内部注册表原样保留为扩展点」：只摘暴露面、不消减装配能力；未来新方向 = 注册表加模板 + 内部调用点传名，而非暴露给用户。
- 链行/回执保留 /goal 身份标注（区分验收环任务行与普通任务行）、去掉模板名；「未知模板报错列可选值」守卫随 token 语法一并删除，守卫只剩无参用法提示与运行中拒绝。
- CLI 与 TUI 同步摘除（CLI 同属用户面，「仅藏 TUI 保留 CLI flag」备选被否决）；旧脚本仍传 `--template=xxx` 时静默忽略不报错。
