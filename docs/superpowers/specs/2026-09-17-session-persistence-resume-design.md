## 交付结论

- 交付会话跨进程/跨天持久化与恢复为一等能力：存储形态经用户裁决取 JSONL 事件日志（方案 B；否决整包快照——回溯需按点重切，与单键覆盖——多会话不共存），追加日志天然是时间轴，未来重放与回溯零格式改动。
- 双入口恢复：TUI /resume 列表选号 + CLI --continue 续最近会话；/new 轮转化归档零成本——旧会话日志天然在盘，/resume 可找回。
- 全会话口径按序重放还原（链/消息/待办/档位/UI 状态）；恢复安全缺省=状态恒 idle、审批登记不持久化（恢复后重新审批）、流式水位等瞬态与 metrics 不还原——「UI 状态全还原」的边界显式登记（输入半文跨天恢复无意义）。
- 收口落盘：事件入内存缓冲、任务收口/轮转/正常退出三点批量追加，运行中不写盘；崩溃最多丢当前任务一段现场；尾行撕裂重放到上一条完整事件并如实提示，损坏/未知版本拒载不静默吞。
- 重放确定性纪律：持久化事件词汇封闭枚举，新增持久化状态必须事件类型+重放动作+重放一致性断言三者同批登记；核心断言=重放后下一轮 prompt 与存档时逐字节一致。
- 验收：多任务+/goal+/compact 后退出，--continue 逐字段一致恢复并续接任务（/goal 续走为首个消费场景）；无档案/损坏/未知版本提示后正常新会话；空会话不落盘。
