## 交付结论

- 交付 TUI 斜杠命令 `/goal`：一条命令直达完整 Loop 验收修正环（此前修正环唯一入口是 CLI run，TUI 任务只能走单 agent 长任务模板）；交互对标 Claude Code 直执行形态——无规划轮、无确认卡，守卫通过直入引擎。
- 方案取舍=薄入口直跑：否决 /plan 同款两段式（职责重叠、多一轮模型调用与一次确认）与 WorkflowDef 统一编排通道（用户入口未建，另立后续规格）。
- 目标语义完全沿用 CLI run 约定：目标内嵌「验收标准：id=描述」段即生效判据，未内嵌走小模型判据兜底（既有行为不变）；用法提示携带内嵌示例，引导书写可判据目标。
- 主链纪律零例外：开跑前入链任务行（带模板标注）、修正环全程主链追加、模板工厂上移单点防 CLI/TUI 两处漂移；/goal 主链与裸任务同构、零新增拼装面，既有前缀稳定回归零新增用例。
- 轮次可见性以终态回执承载（status / iterations / criteria 逐项 ✓✗ / tokens），不加新事件类型（YAGNI）；「每轮 check 结论卡」留作后续独立增强。
- 验收矩阵：无参、未知模板、运行中三守卫均不入链不启引擎；桩模型全链路链上任务行+修正环轨迹+结论行齐备；全量测试与 selfcheck 绿。
