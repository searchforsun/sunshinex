## 交付结论

- 三栏布局重构交付：左栏项目分组（一项目一工作区、组内会话惰拉、组内新建预填项目根）+ 中主区对话 + 右栏多标签侧栏；原 Home 全页退役，设置态由左栏底部切换。
- 标签类型注册表为可扩展核心（目录/文件/Diff/任务/Agents/终端/Web 七类）：新类型=注册表加一条、零壳层改动；标签态每会话独立、同目标去重、单例类型显式声明。
- 真 PTY 终端交付（xterm.js + node-pty 开源栈、专用 WS 双向流、环形缓冲断线重放；用户直打不设审批门）与目录逐层列举端点；Web=iframe+外开引导，原生 webview 归壳批次。
- 设置全链交付：设置页数据全锚既有配置面、零新配置键——GUI 是配置数据的视图与编辑器而非新配置源；含 MCP 两级合并清单+单台真实探测、子智能体定义两级清单+增删改。
- 关键裁决：设置编辑双轨（表单结构化改写——含注释文件拒改并引导原文编辑；高级 JSONC 原文编辑——服务端验证畸形拒存）；生效语义=保存后新会话即刻生效、运行中会话不回改、env 覆盖键显式徽标。
- 设计系统与取舍：单 CSS 设计令牌（青色主色单源、暗色优先、圆润简约），开源组件优先；既有测试钩子 class 原名保留、测试零迁移。
