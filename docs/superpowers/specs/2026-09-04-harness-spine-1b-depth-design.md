## 交付结论

- 总纲 A3「安全唯一链」深度补齐三项交付：压缩重注入闭环（压缩摘要回流后续轮 prompt + 最近 ≤5 文件重读注入）、凭据脱敏（工具结果跨链统一脱敏出口）、文件工具 root 越界校验（resolve 后越出 root 即 deny）。
- 关键取舍（有意不做，YAGNI）：越界校验只守文件工具，exec 命令串不做路径扫描（启发式易绕过、制造假安全感，硬隔离归 1D 多后端）；symlink 不解析留待 1D；敏感文件 deny 规则不在本阶段交付，mask 机制之上可随时叠加 policy 配置。
- 脱敏取「单一代收点」形态：read/grep/exec/dryrun 结果与重读旁路统一过同一套零依赖内置正则模式集，密钥不进上下文与记忆；评审实证发现重读旁路缺口（密钥可经重读明文入上下文）已修复并有回归用例钉住。
- checksum 校验收紧为三态门禁：首次注册基线视为通过、与基线一致按幂等重放处理（不重复注入/记录）、不一致即新一轮压缩正常注入——修正原评审稿「不一致即抛错」与长会话多轮压缩闭环相矛盾的裁决。
- 验收 B1-B5 可证伪判据全过：压缩后摘要必进后续轮且压缩点前原文不再出现、最近文件重读注入、结果与重读条目跨链必脱敏、越界即 deny、相同压缩事件不重复注入/记录。
