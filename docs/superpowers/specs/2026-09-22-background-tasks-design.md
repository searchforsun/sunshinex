## 交付结论

- 交付对标 Claude Code 全形态的后台任务：exec 可后台化（提交即返回、输出流式落文件）、前台命令触超时自动转后台而非失败（sleep 开头除外）、子代理 spawn 两段式开通（预留接缝贯通）。
- 路线取舍「统一账本 + 参数化入口」：任务 ID 空间/生命周期/状态/停止统一承载，执行入口保持既有工具参数化、零新增提交工具；否决「模型拼 shell 停止」（跨平台脆弱、无生命周期账本）与「大一统 task 提交口工具」（与对标口径相反、工具面最大）。
- 查询与停止分工：输出查询复用既有 read（与 Claude Code 废弃 TaskOutput 改读输出文件同构，零安全链改动）；停止走新增 task_stop（跨 kind 统一生命周期语义，专属工具论证成立——工具清单 +1 经用户裁决买断）。
- 超时转后台语义：审批批准的是「跑这条命令」，转后台属执行形态、审批语义不变；观察行回报转后台 + 任务 ID + 输出路径。
- 生命周期对标：前台子代理启动的后台任务随其收口收割，主链任务跨轮存活；零主动完成通知，模型按需读取输出文件（中段零前缀击穿）；任务 ID 为会话内确定性递增序号（零随机源），只出现在链尾。
- 用户面 /tasks 列表回执（双语）；提交失败/输出写失败 fail-bounded 显式报错，不静默吞。
