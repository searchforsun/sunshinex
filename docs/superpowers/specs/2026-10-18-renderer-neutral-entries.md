## 交付结论

- 内核条目渲染中立化交付：自由文本条目（用户/正文/思考/通知/错误）承载裸内容，工具条目仅结构字段（名称/输入/结果）承载、md 退役为恒空——内核零渲染词汇，●/⎿ 等呈现记号归渲染层自绘。
- 对标业界 message API 的自描述条目形态：纯 API 消费者无需渲染知识即可结构化呈现工具行（本设计验收锚点）。
- 三态标识（前/中/后）进条目显式字段、渲染层零推导；失败不设第四态，由结果 ok 字段承载失败面。
- 子代理同构裁决固化：spawn 即普通工具条目、内核零特判——任何「子代理是特殊条目」的形态不进内核；子代理转录与主链行完全同构，投影自由归渲染层。
- 交付形态零兼容：会话档升版 v3 取代 v2，旧档不迁移不归一（版本守卫拒载 + purge 脚本清退），读侧无任何旧形态归一代码——零兼容红线有用例钉死。
