## 交付结论

- 符号链接逃逸闭环（P0-1）：路径类工具判界改为按解析后真实路径归一（判界基准取 root 自身归一一次），root 内链接触达 root 外目标的读/写/检索全部拒绝且拒绝原因含真实路径；root 外链接指回界内正常放行，新建文件写入不受影响；判界 IO 异常一律 fail-closed（验收 S1/S2）。
- 破坏性命令底线（P1-2）：递归删除、mkfs/dd/shutdown 类不可逆命令与下载执行管道在三种权限模式下全部拦截，显式 allow 规则不豁免——底线优先于任何放行规则；rm 非递归与只读白名单操作不受误伤（验收 S3/S4）。
- 威胁模型边界：黑名单定位拦截无意破坏（模型误操作、prompt 注入诱导的常规破坏命令）；编码混淆等有意绕过不在防御范围，由执行环境隔离（Docker/SSH 后端路线）兜底。
