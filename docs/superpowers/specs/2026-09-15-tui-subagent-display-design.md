## 交付结论

- 交付子代理显示层隔离与可视化：子代理事件不进主链消息区与工具行（fork 私有性延伸到显示层、主链渲染零污染），运行中每个子代理在动态区恒高实时面板（头部 spinner+label+耗时+tokens、尾流 3 行轮转），最多 4 并发同屏且整块行数恒定。
- 结束后归档为 Claude Code 式紧凑形态：`● spawn` 调用行 + `⎿ [label]` 结论行，全转录折叠进调用行 detail，复用 Tab/Ctrl+O 既有两层视图展开重放——不新增消息角色、不新增键位。
- 关键裁决：运行中面板落动态区、终态才入 Static——Ink Static 条目渲染后不可变、流式文本无法原位更新，「事件按时间序直写 Static」方案技术不成立被否决；热键聚焦方案与「直接看流式输出」诉求相悖同否。
- 同名并发消歧收敛在 Runner 单点：同 label 并发后到者加 `#N` 后缀，TUI 不复刻后缀逻辑；归档以主链 spawn tool-result 为权威锚点、恰好归档一次。
- 已知边界（接受性取舍）：同 label 并发子代理极端时序下归档归属可能互换（同为同角色任务、结论行与上下文不受影响）；孤儿事件重建暂存、回合结束清空，不炸不悬。
- 前缀缓存零击穿：纯显示层，子代理事件是旁路遥测不进提示词，提示词装配面零改动。
