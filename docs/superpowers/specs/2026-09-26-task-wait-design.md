## 交付结论

- 交付 task_wait 工具补齐后台任务「等待」面：阻塞等待后台任务到终态，终态回执内联 exec 输出尾部/子代理结论——替代此前反复 read 任务日志轮询（每轮烧一次模型调用、无阻塞语义、成功无回执推回）。
- 三类后台任务统一承载（后台 exec、超时转后台 exec、后台子代理）——账本同构单点、与 task_stop 同册；支持批量等待（缺省等全部 running、可指定列表），已终态任务立即幂等回执零等待。
- 关键裁决=方案 A 阻塞等待、主动权在模型：不做完成事件自动尾追进链（任务终态不打断模型）、不做取消等待——超时即返回（缺省 1800s，与命令执行超时同量级），模型自判续等、先做其他事或 task_stop。
- 前缀代价明示论证：新增工具=一次全量前缀断点，论证为后台任务线闭环缺口（read+sleep 无法承载阻塞与终态回执语义）；稳定段零改动——等待能力全部经工具描述分发，子面剔除时指令自动消失。
- 回执语义：全部到终态逐任务一行（id/kind/status/exitCode+输出尾部或子代理结论全文）；超时附「可续等或 task_stop」事实性说明、判断权在模型；未知 id 报错附现存任务清单。
- 验收：终态回执、超时回执、批量混合收口、未知 id、子代理结论全文五态用例齐备；selfcheck tools 行计数 +1；全量门禁绿；等待期间不阻塞主循环（只占一个工具执行槽）。
