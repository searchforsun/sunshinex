# TUI 交互与显示优化设计（思考合并 · 浏览态 · 全文视图 · 命令集）

- 日期：2026-09-11
- 状态：草案（待评审）
- 范围：仅 `src/tui/`；不改引擎、护栏与执行面语义
- 关联：
  - `2026-09-11-long-task-guardrail-design.md` —— 其 §5.4 预留的 `Ctrl+O` 与本设计冲突，调和方案见本文件 §6（两边文档同步加注）
  - `2026-09-10-phase5a-tui-design.md` / `2026-09-10-phase5a-tui-polish-design.md` / `2026-09-10-phase5b-tui-markdown-design.md` —— 既有 TUI 基线，本设计在其上叠加

## 1. 背景与痛点

| # | 痛点 | 现状依据 |
|---|---|---|
| P1 | `Tab` 全局展开会把全部思考/观察全文刷上屏：显示不全、噪音大 | `MessageList.tsx` 的 `expandAll` 透传 |
| P2 | 思考折叠行只有 `Thought for Ns`，扫读时信息量近零 | `session.ts` 收束逻辑只拼秒数 |
| P3 | 长任务运行中缺少全文观察面，想看过程只能等结束或全局展开 | 无对应覆盖层 |
| P4 | 一轮常有多段思考，一段落一行折叠行，重复噪音 | 每次实时区收束各 push 一条 |
| P5 | 命令面薄：无 `/model` `/cost` `/clear` `/export` 等，对标 Claude Code 缺口明显 | 现有命令集仅基础项 |

目标：长任务的思考内容「默认看趋势、按需看全文」，显示噪音显著下降；同时补齐高频命令。

## 2. 方案总览：会话层单源 + 渲染投影

- `messages[]` **不可变**：同轮合并、旧轮收敛、折叠摘要都是**渲染前的纯投影**，不改动存储；`detail` 全文始终保留。
- 新增 `src/tui/display-project.ts`：三个纯函数
  - `mergeSameTurn(items)` —— 同轮思考块合并
  - `convergeOldTurns(items, k)` —— 旧轮收敛（阈值 k=5）
  - `foldSummary(detail, cols)` —— 首行摘要截断（全角安全）
  三者独立单测，不依赖 React 与运行时。
- 新增 `src/tui/commands.ts`：集中承载斜杠命令的解析与执行；既有命令迁入，行为不变。
- 新增 `src/tui/export.ts`：`/export` 的文件写入集中于此，IO 不散落。

## 3. 详细设计

### 3.1 状态扩展（`TuiState`）

| 字段 | 类型 | 初值 | 说明 |
|---|---|---|---|
| `thinkingMode` | `'on' \| 'tail' \| 'off'` | `'tail'` | 实时思考区三态（§3.2） |
| `browseSel` | `number` | `-1` | 浏览态选中下标，-1=未进入（§3.6） |
| `transcriptOpen` | `boolean` | `false` | 全文视图开关（§3.7） |
| `archived` | `ChatItem[]` | `[]` | `/clear` 归档区，`Ctrl+O` 与 `/export` 仍可见 |

不变式：`messages` 只增不改；`archived` 仅 `/clear` 写入；投影结果永不落存储。

### 3.2 实时区三态（`/thinking`，运行中生效）

| 模式 | 行为 |
|---|---|
| `tail`（默认） | 末尾 6 行滚动（现状不变） |
| `off` | 实时思考不显示；收束后折叠行照常落 |
| `on` | 完整实时流（调试用，显式 opt-in） |

只关实时区显示，不改折叠行落盘语义；会话内有效，不做偏好持久化（§9）。

### 3.3 折叠行增强（解 P2）

收束行从只有秒数升级为「时长 · 段数 · 首行摘要」：

```text
✻ Thought for 12s · 3 段 · 先拆 parser 与 loader 的职责边界…
```

- 摘要 = `detail` 首个非空行截断（约 40 列，全角字符按 2 列计），零额外模型调用。
- 测试口径变化：`session.detail.test.ts` / `session.stream.test.ts` 现有 `/^Thought for \d+s$/` 断言随之更新；`selfcheck.ts` 的 TUI 冒烟计数同口径核对。

### 3.4 同轮合并（解 P4）

同一轮内的多个思考块合并为**一条**折叠行：`detail` 以空行连接，时长累加、段数计总量。合并发生在投影层，`messages` 中各段原文不动。

「同轮」判定边界：以**最近一条 user 消息之后**产生的 thinking 条目为同一轮；跨轮永不合并。

### 3.5 旧轮收敛（解 P1 的存量噪音）

投影后只保留**最近 5 条**思考折叠行，更早的收敛为一行：

```text
✻ … 更早 8 段思考 · 合计 94s（浏览态 Enter 展开 / Ctrl+O 全文）
```

浏览态选中该行按 `Enter` 就地展开为原始各段（仅展开投影，不改存储；再按收起）。

### 3.6 行内浏览态（`Ctrl+E`，idle 态进入；解 P1 的按需展开）

```text
  ❯ 帮我重构 config 模块并跑通测试
  ⚙ 写 src/config.ts · +38 −12
❯ ✻ Thought for 8s · 1 段 · 注释只保留业务规则…
  ⚙ 读 config.test.ts · 45 行

  浏览态：↑/↓ 选择 · Enter 展开/收起 · Esc 退出
```

- `Ctrl+E` 进入（选中标记 `❯`），`Esc` 退出；`↑/↓` 移动选中，`Enter` 展开/收起**选中的那一条**。
- 同一时刻只展开一条：可预测、零状态残留；对比多篇用 `Ctrl+O` 全文视图。
- 选中作用于**投影后的列表**（含收敛行）；`messages` 只增不改，选中位置稳定。
- 仅 idle 态可进入；会话切入审批/计划确认时自动退出（审批优先）。
- `Tab` 全局展开（`expandAll`）随之移除，`MessageList` 删除该透传 prop。

### 3.7 全文视图（`Ctrl+O`，运行中可用；解 P3）

```text
┌ 会话全文 · 214 条 · ↑↓/PgUp 滚动 · Esc 退出 ┐
│ [10:32] ❯ 帮我重构 config 模块并跑通测试
│ [10:33] ⚙ read config.ts
│         <结果全文>
│ [10:33] ✻ Thought for 12s
│         <思考全文>
└──────────────────────────────────────────┘
```

- 内容 = 全部消息（含 `archived`）按时间序：用户 / 助手 / 工具入参与结果全文 / 思考全文。
- 运行中可随时开关；窄终端按列宽换行。
- v1 不做搜索（§9、§10）。

### 3.8 快捷命令（解 P5，共 6 条新增）

| 命令 | 语义 | 说明 |
|---|---|---|
| `/thinking on\|off\|tail` | 实时思考三态切换 | 只关实时区，折叠行照常；会话内有效 |
| `/model [名]` | 无参显示当前模型；带参切换 | `TuiRuntime.switchModel()`：`runTask` 每次以 modelRef 装配，切换只影响后续 run，上下文记忆不丢 |
| `/cost` | 账本明细：runs · 累计 tokens · 各轮时长 | 取 ledger 既有 per-run 字段，不新增埋点、不报金额 |
| `/todos` | 显示当前计划待办与进度 | |
| `/export [路径]` | 会话全文导出 Markdown | 缺省 `.data/exports/session-<时间戳>.md`（目录加入 gitignore）；写入集中在 `export.ts` |
| `/clear` | 清空主界面消息区 | **归档而非丢弃**：`messages` 移入 `archived`，`Ctrl+O` 与 `/export` 仍见全量；区别于 `/new` 的软重置 |

`/help` 同步更新清单；命令解析与执行统一收口 `commands.ts`。

## 4. 键位总表

| 键 | 现状 | 改后 |
|---|---|---|
| `Tab` | 斜杠补全 / idle 态全局展开切换 | **仅斜杠补全**（全局展开移除，由浏览态替代） |
| `Ctrl+E` | — | idle 态进入浏览态 |
| `Esc` | — | 退出浏览态 / 关闭全文视图 |
| `Ctrl+O` | — | 全文视图开/关（运行中可用） |
| `↑/↓`、`Enter` | 历史回溯 / 发送 | 浏览态内变为选择与展开；其余场景不变 |

## 5. 错误与边界

- `/export` 路径不可写：system 行提示并以默认路径重试一次，再失败如实报错。
- `/model` 未知名称：提示用法与当前值，不盲目报错。
- 窄终端：折叠行摘要按列宽截断；全文视图按列宽换行。
- 审批/计划确认优先于浏览态与全文视图（浏览态自动退出；全文视图保持打开但不拦截审批框）。

## 6. 与长任务护栏 spec 的关系（键位调和）

- 本设计将 `Ctrl+O` 划归**会话全文视图**；护栏 §5.4 预留的 `Ctrl+O`（FlowStrip 展开）就此让位：**将来 FlowStrip 的多行面板并入全文视图承载**（一个覆盖层同时承载过程与流程），不再单开。
- 两份文档同步加注（护栏文档 §5.4 已加「键位调和」注记）。
- `Esc` 中断运行任务不在本轮：属执行面改动，另立议题。

## 7. 测试策略

- **投影纯函数**（`display-project.test.ts`）：同轮合并（多段→一条、时长累加）、收敛阈值（k=5）、摘要截断（全角安全、空 detail 兜底）、收敛行展开还原。
- **命令**（`commands.test.ts`）：`/thinking` 三态、`/model` 显示与切换生效于后续 run、`/cost` 数据拼装、`/clear` 归档且 `Ctrl+O` 可见、`/export` 落盘内容与默认路径、不可写重试。
- **渲染/交互**：浏览态进入/选择/展开/退出、运行中禁入浏览态、`Ctrl+O` 开关与归档内容可见、`Tab` 回归纯补全（回归用例）、审批框优先。
- 全量单测 + `selfcheck` 冒烟不回归（计数断言同口径更新）。

## 8. 阶段划分与验收

| 阶段 | 内容 | 验收 |
|---|---|---|
| A | 投影纯函数 + 同轮合并 + 折叠行增强 | 长思考会话主界面仅见增强折叠行；单测全绿 |
| B | 旧轮收敛 + 浏览态 + `Tab` 收敛 | 6 轮以上会话思考行 ≤5+1；`Tab` 不再全文刷屏 |
| C | 全文视图 + `/clear` 归档 + `/export` | 运行中可开全文；clear 后导出仍含全量 |
| D | 命令集 + `/help` | 六命令行为符合 §3.8 |

## 9. 明确不做

全文视图内搜索 · 偏好持久化 · 鼠标 · `/pipeline`（B+ 另立）· 思考的 LLM 摘要（保持零额外调用）· `Esc` 中断运行任务（执行面，另立）。
