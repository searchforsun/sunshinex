## 交付结论

- 压缩摘要改由当前会话模型一次调用生成六要素结构化交接摘要（目标/关键约束/进度/已验证/未完成与下一步/策略依据），替代「原文截头」的低密度确定性摘要。
- 模型路径任何失败（抛错/空输出/超预算跑飞）自动回退既有确定性截断——压缩永不因摘要失败而失败，失败面零新增（验收 A2–A4）。
- 关键裁决（方案 A）：模型只接管「怎么讲」、不接管「压什么」，确定性选块与预算白名单完整保留为回退底线；模型全权压缩（方案 C）否决——回退底线废弃且测试钉不住。
- /compact 与自动压缩收敛为同一压缩协调单点（两入口只传参不拼装），/compact 补链参与压缩、成功后折叠链前缀，消除两入口语义分叉（验收 A6–A7）。
- 前缀缓存零新增击穿：checksum 仍锚定选中块输入、摘要调用为独立一次性 prompt 不进主链、压缩块与链不双份（验收 A1/A9）。
