## 交付结论

- 在不改动 reactor 协议语义与工具链的前提下把 TUI 提升到产品级交互面，八条诉求全数交付：启动横幅（太阳图徽+版本/模型/命令提示）、流式正文逐字上屏、思考实时可见、工具步骤英文两行、常驻边框输入框、去角色标签的消息渲染（助手裸文本、用户整行底色）、状态栏本轮 tokens 与 runs/ctx 命中率、运行态 spinner。
- 事件面以加法补齐三通道（答复增量/思考增量/用量），模型侧经 adapter 思考通道转发、展示侧从 JSON 协议增量还原答复文本且协议骨架一律不上屏；端点不回思考则思考区整体不出现。
- 关键取舍「权威性划分」：流式提取仅服务观感，消息终稿一律以 done 载荷为准——提取器任何偏差只影响过程显示、不影响内容正确性；前缀/缩进/着色一律由渲染层补齐，归约层只存原始正文。
- 降级链完备：非 JSON 输出原文透传、提取失败终稿兜底补齐、usage 缺失照显 0 tokens 不伪造估算、非 TTY 回退 80 列。
- YAGNI 边界：不升级 ink、不做主题配置/鼠标交互/Markdown 渲染/滚动视口（长会话交终端 scrollback）、不加思考协议键、CLI 行为零改动。
- 验收：tsc strict 零报错、全量测试绿（含提取器/渲染规则/事件归约新用例与旧标签断言按新口径修订）、selfcheck 扩合成事件流冒烟、真实终端手工验收清单全过。
