## Rulings(计划级)

1. **diff 端点**:`GET /session/:id/diff?callId=` → 从该会话 writeSnapshot 体系取 pre-image + 磁盘现文件(post-image)→ `{path, oldContent?, newContent, truncated?}`;blob 查询面现场核(write-snapshot.ts);callId 无对应 blob(非 write 工具/无快照)→ 404 `{error:'no snapshot'}`;**新旧各限 512KB 截断**(同 /file 口径);路径判界同 /file(blob 路径天然根内,post 读同判界)。
2. **GUI diff 面板升级**:write 条目展开改为「新文件内容(左=pre-image 若有,右=现文件)」双列——connection 增 `fetchDiff(sessionId, callId)`;DiffPanel 复用(oldStr=oldContent)。
3. **pending 内容恢复**:daemon snapshot `pending` 段每项增 `req: unknown`(直接序列化挂起 req);Chat reseed 时 `snapshot.pending` 经 `addCard` 重建(pid/kind/req)——**跨会话/刷新挂起卡恢复闭环**。
4. **小项**:Chat unmount cleanup `seedGenRef.current++`;Chat toolInputs 在 reseed/reset 时清空(Map clear);Files 加载请求序守卫(requestId ref,last-arrival-wins)。
5. **ROADMAP 5B 回写**:5B 清单 GUI spec 先行/对话交互/代码预览 diff 各项标注交付,「工作流可视化编排(任务委派式看板)」从后置 v2 改为 **G5 已交付**(会话中心修正后范围);壳批次(托盘/打包)维持后置注记。
