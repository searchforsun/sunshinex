# G3 对话页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 GUI 对话页:流式 chat reducer、提交/中断/steering/状态栏、md 渲染、重连 seq 协议与连接层状态机、daemon 静态挂载——验收「提交→流式渲染→done 收段;断线重连恢复」。

**Architecture:** **seq 单调协议**解重连双应用:daemon 泵给每个 SessionEvent 发单调 `seq`,帧 `{kind:'event', seq, e}`,`GET /snapshot` 响应带 `lastSeq`;客户端重连 = 取新 snapshot 重置基线(记 lastSeq)→ 丢弃补发帧中 `seq ≤ lastSeq` 者 → 增量续推——WS 保持单向下行(G-D5 不破)。boardEventFrom 自 tui/session.ts 抽纯模块 `src/taskboard/translate.ts`(session.ts 转发导出,gui 板投影实时化消费)。TranscriptCollector 扩 kind 对齐 spec §5.3 六类。

**Tech Stack:** TypeScript(tsc strict 主仓/gui typecheck)、React 18、react-markdown(+remark-gfm,gui dep)、既有 ws/vitest。

**Spec:** `docs/superpowers/specs/2026-10-06-gui-v1-design.md`(§5.2 chat reducer、§5.3 snapshot、§6 对话页、§9 重连、§12 G3;G2 终审交接清单逐项)。

## Global Constraints

- 主仓 tsc strict 零报错、`pnpm test` 0 败(全量门禁仅 T6 控制器后台);gui typecheck+test 绿(`pnpm --filter sunshinex-gui test` 全链);看门狗 600s 协议(逐任务聚焦,单命令 ≤8min,长命令后台)。
- WS 保持单向下行;帧/快照协议改动须 daemon 先行(gui 跟随)。
- 事件 payload 结构化禁 ANSI;chat reducer 只存 md 原文。
- 注释中文决策风格;gui 源入 typecheck(exclude 白名单外零新增)。
- 受保护测试零改动(session.test 族);session.ts 只做转发导出不重构。

## Rulings(计划级)

1. **seq 协议**:泵计数器从 1 单调;帧 `{kind:'event', seq, e}`(approval/ask 帧不带 seq——挂起面,重连由 daemon 重发未决请求,G4);snapshot 增 `lastSeq`(当前计数);补发缓冲存 seq。
2. **重连语义**:客户端 connecting→open→reconnecting(指数退避 1s 起 ×2 帽 30s)→closed(显式);重连成功回调 `onResync(snapshot)` 由页面重置全部投影(chat/board/delegations/status)。**不做**增量缝隙拼接(spec §9 裁定维持:重置重放)。
3. **boardEventFrom 抽家**:`src/taskboard/translate.ts`(纯模块,零 TUI 依赖);session.ts `export { boardEventFrom } from '../taskboard/translate'` 转发(既有导入面零改);gui projection re-export 自新家。
4. **TranscriptCollector kind 扩**:`'user' | 'assistant' | 'tool' | 'notice' | 'error'`(error 事件→error 条;notice→notice 条;delegation 起止一行摘要条 kind 'notice';agent-message→notice 条 `[from → to] text`)——§5.3 六类的归档面全集。
5. **静态挂载**:daemon GET 非已知路径 → dist-gui 存在则静态服务(`.mimeType` 映射 + index.html 兜底,仅 GET);不存在保持 404+hint。目录探测启动一次缓存。
6. **md 渲染**:react-markdown+remark-gfm(gui dep);代码块纯 `<pre>`(高亮 G6 预览页一并)。
7. **steering 判定**:运行中输入框提交 = POST /steer,空闲 = POST /submit(客户端按 status 分流);daemon 增 `POST /steer {text}` → `harness.steering.push(text)`(现场核对 SteeringChannel API,200 空体)。
