# G5 看板(P3 验收)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 GUI 看板页(列表/DAG 双视图、teammate 侧栏、gate 审批)——编排 spec P3 验收逐条兑现;并收编 G4/G3.5 交接小项。

**Architecture:** daemon 增 `POST /session/:id/board/review`(gate 审批映射 taskboard.review)与 snapshot 扩段(`team` 存活名单+busy、`pending` 未决 pid 列表——顺手解跨会话卡恢复);GUI `pages/Board.tsx`(列表=投影行/DAG=dependsOn 分层 SVG;gate 行 Approve/Deny)挂进 G3 既有的 Chat|Board tab(唤醒禁用占位);board/delegations 投影在 `onResetSession` 会话维重置(G3.5 交接 d 项)。交接小项:Home journal 行 Delete 移除(journal 是 append-only 历史,daemon 会话删除在 Chat 顶栏)、newSession mode 面、未知 mode 400、ghost-pending 硬化(asker 注册时查 signal)、中断卡滞留(status idle 清卡)、serve --mode。

**Tech Stack:** TypeScript strict(主仓+gui)、React 18、vitest、零新依赖(DAG 手写分层 SVG)。

**Spec:** `docs/superpowers/specs/2026-10-06-gui-v1-design.md`(§6.3 看板、§4.1 端点、§12 G5)、`docs/superpowers/specs/2026-10-04-multi-agent-orchestration-design.md`(§10.3、§13 P3:任务列表→看板、dependsOn→DAG 自动推导、teammate→侧栏)。

## Global Constraints

- 主仓 tsc strict 零报错、`pnpm test` 0 败(全量门禁仅 T3 控制器后台);gui typecheck+test 绿;看门狗 600s 协议。
- **同 root 多会话共享 teams/ 存储但各持内存 TaskBoard 实例**——board/review 经某会话实例落 events.jsonl,他会话经 reseed 对齐(已知边界,回写记);review 端点按 :id 会话路由。
- 事件 payload 结构化禁 ANSI;DAG 布局纯函数(可测)。
- 注释中文决策风格。

## Rulings(计划级)

1. **gate 审批会话路由**:`POST /session/:id/board/review {taskId, approved}` → 该会话 `runtime.harness.taskboard.review(taskId, {approved})`;Result fail 透传 400 `{error}`;未知 :id 404。
2. **snapshot 扩段**:`team: {name: string; busy: boolean}[]`(经 harness.team: aliveNames + get(name).isBusy()——TeamRegistry 现场核);`pending: {pid: string; kind: 'approval'|'ask'}[]`(挂起表过滤本会话)——GUI 重播种时渲染未决卡(跨会话卡恢复闭合)。
3. **DAG 分层纯函数**:`layoutBoard(tasks): {id; layer; x; y}[]`——Kahn 分层(同层横排,层间纵排;环/缺依赖防御跳过);GUI 画 SVG 盒+线;**布局计算与渲染分离可单测**。
4. **board 投影会话维重置**:App 的 `onResetSession(sessionId)` 分支增清 board/delegations 投影(现为连接级 onReset 才清——G3.5 交接 d 项);Board 页消费 App 级投影(与 Chat 同源)。
5. **Home journal 行 Delete 移除**:journal 是 append-only 历史(daemon 会话 delete 保留 journal 是 G4 裁定);Chat 顶栏加 Delete(daemon 会话)替代入口;G4 e2e 的 Home delete 断言相应迁移。
6. **交接小项归置**:newSession(root, mode?) 连接面(缺省 dontAsk);/session/new 未知 mode 400(白名单外拒);ghost-pending——manual asker 闭包注册前查该会话 current.abort.signal.aborted,已中止即直接 resolve deny/dismissed 不入表;中断卡滞留——Chat 在 chatReducer status 转 idle 时清本地卡列表(事件驱动,无需新帧);serve --mode 别名 --manual(两 flag 同义)。
7. **跨会话 board 同步边界(回写记)**:两会话同 root 各持 TaskBoard;A 会话 review 落 events.jsonl,B 会话内存板不知——B 的 reseed(重连/重开)对齐;v1 接受,不建跨会话失效通知。
