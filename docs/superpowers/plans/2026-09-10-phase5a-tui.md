**Goal:** 交付 `sunshinex tui` 交互式会话入口——流式渲染、权限审批终端化、plan-mode 与待办同步，对标 Claude Code。

**Architecture:** 三层——Ink 组件层（纯渲染）→ SessionController（纯 TS 状态机）→ Harness/Reactor 运行时复用（不 fork 不旁路）。运行时唯一侵入面 = 可选 `onEvent` 事件流 + 可选 `asker` 审批注入；会话同源（同一 ContextManager 连续多次 `reactor.run`）。

import assert from 'node:assert/strict';
import * as fs from 'fs';
import * as os from 'os';
import * as path from 'path';
import { Reactor } from './reactor';
import { ProcessSandbox } from './security/sandbox';
import { SecurityGuard } from './security/guard';
import { PolicyEngine } from './security/policy';
import { SafetyChain } from './security/chain';
import { DryRun } from './security/dryrun';
import { ToolRegistry } from './tools';
import { builtinTools } from './tools/builtin';
import { ContextManager } from './context';
import { FileStore } from '../storage/adapter';
import { ModelAdapter, ScriptedAdapter } from '../model/adapter';
import { SessionEvent } from '../types';

function makeReactor(tmp: string, adapter: ModelAdapter, onEvent?: (e: SessionEvent) => void): Reactor {
  const store = new FileStore(path.join(tmp, '.data'));
  const safety = new SafetyChain(new SecurityGuard(new PolicyEngine(), 'dontAsk'), new ProcessSandbox(), new DryRun(), tmp);
  const registry = new ToolRegistry();
  for (const t of builtinTools(safety, tmp)) registry.register(t);
  const context = new ContextManager(tmp, store);
  return new Reactor({ registry, safety, context, model: adapter, ...(onEvent ? { onEvent } : {}) });
}

test('事件流：正常单步 run 发射 step→token*→route→done，无 onEvent 零副作用', async () => {

  try {
    const events: SessionEvent[] = [];
    const r1 = await makeReactor(tmp, new ScriptedAdapter(['{"done":true,"reply":"ok"}'])).run({ goal: 'g1' }, { maxSteps: 2 });
    assert.equal(r1.done, true, '无 onEvent 缺省零副作用');
    const r2 = await makeReactor(tmp, new ScriptedAdapter(['{"done":true,"reply":"ok"}']), (e) => events.push(e)).run({ goal: 'g2' }, { maxSteps: 2 });

    assert.ok(types.includes('step') && types.includes('token') && types.includes('route'), `应含 step/token/route，实际 ${types.join(',')}`);

```ts
// import 区追加
import { ApprovalDecision, ApprovalRequest } from '../../types';

export class SecurityGuard {
  // 构造器不变；追加三个私有/公有成员
  private asker?: (req: ApprovalRequest) => Promise<ApprovalDecision>;
  /** 会话级 always 登记面（内存态；会话结束由调用方 clearSessionAllows） */
  private sessionAllows = new Set<string>();
  private seq = 0;

  /** 终端化审批注入（TUI/GUI 装配点）；传 undefined 即卸载 */
  setAsker(asker?: (req: ApprovalRequest) => Promise<ApprovalDecision>): void {
    this.asker = asker;
  }

  clearSessionAllows(): void {
    this.sessionAllows.clear();
  }

  /** 异步决策旁路：硬底线/deny/只读直通与同步版一致；ask 段接入 asker */
  async preToolUseAsync(tool: string, input: unknown): Promise<GuardDecision> {
    const sync = this.preToolUse(tool, input);
    const askable = this.mode === 'manual'
      && this.policy.decide(tool, this.extractSpecifier(tool, input)) === 'ask'
      && !(tool === 'Bash' && this.isReadonlyCommand(this.extractSpecifier(tool, input)))
      && !(tool === 'Read' || tool === 'Grep' || tool === 'Glob');
    if (!askable || !sync.allowed === false || sync.allowed) return sync;
    // manual + ask + 非白名单 → asker 链路
    if (!this.asker) return sync; // 无 asker：维持阶段一拒绝文案
    const specifier = this.extractSpecifier(tool, input);
    if (tool === 'Bash' && this.sessionAllows.has(specifier)) return { allowed: true };
    const req: ApprovalRequest = {
      id: `ap-${++this.seq}`,
      kind: tool === 'Bash' ? 'command' : tool.startsWith('mcp__') ? 'mcp' : tool === 'WebFetch' ? 'webfetch' : 'write',
      subject: specifier,
      reason: 'manual 模式需交互确认',
    };
    let d: ApprovalDecision;
    try {
      d = await this.asker(req);
    } catch (e) {
      return { allowed: false, reason: `COMMAND_DENIED: asker 异常（${e instanceof Error ? e.message : String(e)}）` };
    }
    if (d === 'deny') return { allowed: false, reason: 'COMMAND_DENIED: 用户拒绝' };
    if (d === 'always') this.sessionAllows.add(specifier);
    return { allowed: true };
  }
}
```

实现纪律注：`sync.allowed` 为 true 时直接短路返回（askable 判定与 sync 判定可能差异，以 sync 结果为权威，避免双评口径漂移）；`sync.allowed === false` 时仅当「manual + ask + 非只读 + 非 deny/硬底线」才进 asker——deny 规则与硬底线的拒绝 reason 含 `deny 规则匹配`/`破坏性命令`/`仅允许只读操作`/`未登记`/`白名单`/`URL 非法`，与 `manual 模式需交互确认` 可区分，askable 判定以上述组合条件为准而非文案匹配。

```ts
import { Harness } from '../harness';
import { ModelAdapter } from '../model/adapter';
import { ApprovalDecision, ApprovalRequest, RunResult, SessionEvent } from '../types';

export interface TuiRuntimeOpts {
  root: string;
  model?: ModelAdapter;
  onEvent?: (e: SessionEvent) => void;
  mode?: 'dontAsk' | 'manual' | 'plan';
  onApproval?: (req: ApprovalRequest) => Promise<ApprovalDecision>;
}

export interface TuiRuntime {
  harness: Harness;
  runTask(goal: string, opts?: { maxSteps?: number }): Promise<RunResult>;
}

export function createRuntime(opts: TuiRuntimeOpts): TuiRuntime {
  const harness = new Harness({
    root: opts.root,
    ...(opts.model ? { model: opts.model } : {}),
    ...(opts.onEvent ? { onEvent: opts.onEvent } : {}),
    ...(opts.mode ? { mode: opts.mode } : {}),
  });
  if (opts.mode === 'manual' && opts.onApproval) harness.security.setAsker(opts.onApproval);
  return {
    harness,
    runTask: (goal, o) => harness.reactor.run({ goal }, { maxSteps: o?.maxSteps ?? 12 }),
  };
}
```

`index.ts` 改动（三处，全部追加式）：① `HarnessOptions` 追加 `onEvent?: (e: SessionEvent) => void;`；② Reactor deps 追加 `...(opts.onEvent ? { onEvent: opts.onEvent } : {})`；③ 字段区追加 `readonly model: ModelAdapter;` 与 `readonly store: FileStore;` 并在构造器赋值（`this.model = opts.model ?? new StubAdapter()`，Reactor 构造同步改用 `this.model`；`this.store = store`）。
