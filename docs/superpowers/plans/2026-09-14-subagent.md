# 子 agent 执行单元实施计划（SubagentRunner + spawn 双入口）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `docs/superpowers/specs/2026-09-14-subagent-design.md` 落地子 agent 执行单元：SubagentRunner 单一权威（三形态解析 → fork 组装 → 执行 → 结论回写 → 工具面收窄），spawn 内置工具（主任务动态派生，同步 + 同轮批量并行）与 graph 角色节点（收敛薄入口）双形态同批交付。

**Architecture:** `src/harness/subagent.ts` 为子代理生命周期唯一权威——AgentRegistry（`agents/{id}/agent.md` 装配期一次性加载 fail-fast + ROLE_PRESETS 四角色内建注册，预设常量自 graph 迁入 harness 修正分层方向）；`runSubagent` 以 `seedHistory = [...chainView(), 角色行?, 任务行]` 起 fork 作用域 Reactor（行组装对齐 graph 先例：角色行 `action:'role'`、任务行 `action:'task'`，终态回写 `action:'node'/'note'`），私有步骤零主链回写、终态恰好回写一行；子工具面 = 父 registry `derive`（缺省 − spawn，显式 `tools` 收窄/放开）；spawn 工具（category `subagent`）薄委托 Runner，同轮 `tools` 数组批量并行、同层 fork 并发上限 4；graph `makeRoleAgent` 收敛为薄入口调 Runner（消除与 Runner 的双处拼装）。

**Tech Stack:** TypeScript strict（CommonJS）+ Node ≥ 22.9 + node:test；pnpm；零新增依赖。
